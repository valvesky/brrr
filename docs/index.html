brrr

Full power while the heavy work runs. Back to the mode you had when it stops.

brrr is the sound the fans make. It watches the programs you choose — a game, a zip, a video export, a compile — and switches the operating system’s performance mode on while one of them is running. When the last one exits, it puts back what was there before.

Download How it behaves

What it does

Performance mode, only while you need it

You pick the apps

A list of compilers is already there. Add any other process name from the tray, or with brrr --add NAME. Names are at most 15 bytes, and on Windows you leave off .exe.

The whole machine switches

The power mode is system-wide. While brrr is boosting, everything runs in the performance mode, not only the program that triggered it.

Your choice wins

When the work finishes, brrr restores the mode it found. If you change the mode yourself in the middle, it leaves that choice alone until the watched programs exit.

Download

Latest release

Each button is the file from the latest GitHub release. Releases are published when a version tag is pushed. If a file is not there yet, open the releases page. Install steps are on the install page.

Windows 10 and 11 brrr-windows-setup.exe One installer for x64 and ARM. No administrator account. macOS 12 or later brrr-macos.dmg Universal app, Apple silicon and Intel. Not notarized. Linux, x86_64 brrr-linux-x86_64.tar.gz Static binary. Needs power-profiles-daemon or tuned-ppd. Linux, aarch64 brrr-linux-aarch64.tar.gz Same program, for 64-bit ARM.

Windows without an installer: brrr-windows-x86_64.exe and brrr-windows-aarch64.exe. On Omarchy, skip the downloads and add the plugin.

Where it runs

The same idea, each system’s own switch

Windows

On the Balanced plan, Power mode goes to Best performance. No administrator rights. Windows 10 version 1809 or later, and Windows 11. Install

Linux

A performance hold on power-profiles-daemon, or tuned-ppd which speaks the same interface. A tray icon your desktop draws itself. Install

macOS

Turns Low Power Mode off for the current power source and, on MacBook Pros that have it, turns High Power Mode on. One password, once. Install
