Install

Windows

  1. Run brrr-windows-setup.exe. No administrator rights needed.
  2. Its icon appears in the notification area, and it starts when you sign in.

Linux

  1. Make sure power-profiles-daemon or tuned-ppd is running. Most distributions have one.
  2. Put brrr on your PATH and start it:
tar -xzf brrr-linux-x86_64.tar.gz
mv brrr ~/.local/bin/
brrr --install   # at every login
brrr --tray &    # and now

macOS

  1. Open brrr-macos.dmg and drag brrr to Applications.
  2. Open it. The first time, right-click it and choose Open.
  3. From its menu bar icon, choose Allow Power Mode Switching… and enter your password once.

Omarchy

omarchy plugin add \
  https://github.com/valvesky/brrr.git \
  --enable

That’s it. Nothing to build.

FAQ

How do I add an app?

Choose Add app… in brrr’s menu (or the Omarchy widget) and type its process name, like ffmpeg. On Windows, leave off .exe.

Which apps are boosted by default?

7-Zip, ffmpeg, Blender, OBS, HandBrake, DaVinci Resolve and the usual compilers, plus WinRAR, After Effects and Photoshop on Windows.

Why didn’t it switch on Windows?

Best performance is a power mode of the Balanced plan. On another plan brrr switches to High performance if you have it, and on High or Ultimate performance you’re already at full power.

Why does macOS ask for my password?

Switching Low Power Mode needs administrator rights, so brrr asks once and allows only those power commands. The app isn’t notarized, which is why the first launch needs right-click › Open.

Does it work on battery?

Yes, and it drains the battery faster while a heavy app runs. Turn off automatic boost in the menu when you’d rather save power.

How do I uninstall it?

  • Windows: Settings › Apps › brrr
  • Linux: brrr --uninstall, then delete the file
  • Omarchy: omarchy plugin remove raw.brrr
  • macOS: run this, then trash the app:
    /Applications/brrr.app/Contents/MacOS/brrr --uninstall
